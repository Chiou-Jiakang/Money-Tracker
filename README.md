# Money Tracker｜個人財務管理系統

Money Tracker 是一套使用 JavaScript、Node.js、
Express 與 SQLite 開發的個人財務管理網頁系統。

## 專案目標

建立一套能夠記錄、管理、查詢及分析個人收入與
支出的全端網頁應用程式。

## 預計實作功能

- 財務總覽 Dashboard
- 收入與支出紀錄管理
- 交易分類管理
- 日期、類別及金額條件查詢
- 每月財務統計與分析
- Chart.js 統計圖表
- CSV 資料匯出

## 預計使用技術

- Frontend：HTML、CSS、JavaScript
- Backend：Node.js、Express
- Database：SQLite
- Charts：Chart.js
- Version Control：Git、GitHub
